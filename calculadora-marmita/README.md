# Calculadora de Custo de Marmita

Projeto independente, sem dependências (HTML + CSS + JS puros).

## Como usar

Abra `index.html` diretamente no navegador, ou sirva a pasta com qualquer servidor estático:

```bash
npx serve calculadora-marmita
```

## Funcionalidades

- Cadastro dos ingredientes da receita (quantidade usada e preço por unidade)
- Custo de embalagem e outros custos fixos por marmita
- Rendimento da receita (quantas marmitas ela produz)
- Margem de lucro desejada
- Cálculo automático de: custo total da receita, custo por marmita, preço de venda sugerido e lucro por marmita
- Os dados ficam salvos no navegador (localStorage), então não somem ao recarregar a página
